# Task Manager

## Overview

Task Manager is a React web application that allows users to create, complete, delete, and filter todo tasks. The application also includes a contact page with a controlled React form.

## How to Use

1. Open the application.
2. Use the Todos page to add a new task.
3. Click a task to mark it as completed.
4. Use the Delete button to remove a task.
5. Use the All, Completed, and Incomplete buttons to filter tasks.
6. Use the Contact page to enter contact information and comments.

## Functionality

- Add new todo tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by all, completed, or incomplete
- Navigate between Todo and Contact views
- Controlled contact form using React state

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- React Router
